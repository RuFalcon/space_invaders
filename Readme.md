# Космические Захватчики (Space Invaders Clone)

Простая игра-клон Space Invaders, написанная на Python с использованием библиотеки Pygame.

## Описание

Игрок управляет кораблем внизу экрана и должен уничтожать ряды наступающих инопланетных захватчиков. Враги двигаются из стороны в сторону и постепенно спускаются вниз. Они также стреляют в игрока. Цель - уничтожить всех врагов до того, как они достигнут нижней части экрана или уничтожат корабль игрока.

## Требования

*   Python 3.x
*   Pygame

## Установка

1.  **Установите Python:** Если у вас еще нет Python, скачайте и установите его с [официального сайта](https://www.python.org/).
2.  **Установите Pygame:** Откройте терминал или командную строку и выполните команду:
    ```bash
    pip install pygame
    ```

## Запуск игры

1.  Убедитесь, что в директории с игрой (`invaders.py`) находятся следующие файлы изображений:
    *   `player.png` (корабль игрока)
    *   `enemy.png` (корабль врага)
    *   `bullet.png` (пуля игрока)
2.  Откройте терминал или командную строку, перейдите в директорию с игрой и выполните команду:
    ```bash
    python invaders.py
    ```

## Управление

*   **Стрелка влево:** Движение влево
*   **Стрелка вправо:** Движение вправо
*   **Пробел:** Выстрел
*   **R / Пробел (после окончания игры):** Рестарт
